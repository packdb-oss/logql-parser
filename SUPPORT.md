# Support

For usage questions use the repository issue tracker (https://github.com/packdb-oss/logql-parser/issues). Report reproducible defects with the issue
template; include version, operating system and a small sanitized example. Do not
include passwords, tokens, private endpoints or customer telemetry. Security reports
follow SECURITY.md and conduct reports follow CODE_OF_CONDUCT.md.

Support is community best effort. README defines supported platforms, feature flags,
protocol versions and known limitations. Where substantiated, “used in production”
describes deployment use only, with no quality, HA or other commercial guarantee.
Maintainers may close duplicate, unreproducible, off-topic or unsupported requests
with an explanation.
